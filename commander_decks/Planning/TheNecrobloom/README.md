## Strategic Summary
Operates as a pure **Landfall & Field of the Dead Engine** in the command zone. Once 7 differently named lands are in play, each land drop produces a 2/2 Zombie, stacking alongside the actual [Field of the Dead](https://scryfall.com/card/m20/247/field-of-the-dead?utm_source=api) to create two 2/2 Zombies per drop. The deck accelerates using [Spelunking](https://scryfall.com/card/lci/213/spelunking?utm_source=api) (ensuring mass reanimated lands enter untapped), [Ancient Greenwarden](https://scryfall.com/card/otc/186/ancient-greenwarden?utm_source=api) (doubling landfall triggers), and [Cultivator Colossus](https://scryfall.com/card/inr/190/cultivator-colossus?utm_source=api), closing games with [Craterhoof Behemoth](https://scryfall.com/card/tdm/138/craterhoof-behemoth?utm_source=api) overrun or the [Thespian's Stage](https://scryfall.com/card/2xm/327/thespians-stage?utm_source=api) + [Dark Depths](https://scryfall.com/card/dmr/244/dark-depths?utm_source=api) (20/20 Marit Lage) combo. Dredge 2 on graveyard lands is utilized strictly as an insurance policy to guarantee hitting land drops every turn.
